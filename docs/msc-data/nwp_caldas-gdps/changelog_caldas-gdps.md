## Le mercredi 1er décembre 2021

### Retrait du Système canadien d'assimilation de données de surface dans le SGPD

À compter du mercredi 1er décembre 2021, le Centre météorologique canadien (CMC) cessera la production du Système canadien d'assimilation des données de surface dans le [SGPD](../nwp_gdps/readme_gdps.md) (SCanADS-SGPD).
